University Agent

プライバシーポリシー

制定日：2026年9月15日

1. 対象

University Agent（以下「本アプリ」）は、運営者本人が自分の授業資料を整理するための個人用ツールです。利用者は運営者本人に限られます。

2. 取得する情報

本アプリは、Google アカウントでの認可に基づき、Google ドライブ API の https://www.googleapis.com/auth/drive.file 権限だけを使います。この権限では、本アプリが作成したファイルとフォルダだけにアクセスでき、ドライブ内のその他のファイルは読み取りません。

本アプリが扱うのは、利用者本人がアップロードした授業の録音・動画・写真・資料と、そこから本人の端末で作成した文字起こし等の処理結果です。氏名・メールアドレス・連絡先などのプロフィール情報は取得しません。

3. 利用目的

取得した情報は、利用者本人の Google ドライブへの保存、保存したファイルの確認、利用者本人の学習用ノートの作成にのみ使います。

4. 保存場所と第三者提供

ファイルは利用者本人の Google ドライブと、利用者本人が管理する端末に保存されます。学習用ノートを作るため、ファイル名・保存日時・ドライブ上のリンク・文字起こし等を、利用者本人のアカウントで使っている Notion と ChatGPT に送ることがあります。これは利用者本人が求めた機能のためだけに行います。本アプリは情報を販売・広告目的で利用せず、上記以外の第三者に提供しません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. 認証情報の管理

Google の認可で発行される更新用トークンは、利用者本人の端末の保護された保存領域に保管し、公開したり他者と共有したりしません。

7. 削除とアクセスの取り消し

利用者は、Google アカウントのサードパーティ アクセス設定から本アプリのアクセスをいつでも取り消せます。本アプリが作成したファイルは、Google ドライブから削除できます。

8. 変更

本ポリシーを変更する場合は、このページを更新します。

9. 連絡先

本ポリシーに関するお問い合わせは、GitHub の Issues からお願いします。
